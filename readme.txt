A monochrome classic WordPress theme for an independent publisher.

== Description ==

Black Book retains native Templates, The Loop, Menus, Widgets and Customizer. It provides complete 5:8 cover frames, mobile-first single-book introductions, book archives and uncropped book search thumbnails. BookPress Catalog 1.0.0 separately owns book content and metadata. Ordinary Posts and Pages remain available without the plugin.

Choose a featured book and headings in Customizer, adjust 26 palette roles and edit the black Publisher Statement band through Widgets. Saved homepage content overrides default modules. No demo import or migration runs on activation; no commerce or tracking is included.

== Installation ==

1. Install and activate the separately supplied BookPress Catalog plugin.
2. Upload black-book to wp-content/themes and activate Black Book.
3. Assign menus, static homepage and posts page; update Customizer and Widgets.
4. Add real covers, excerpts, body introductions, authors and optional publication fields.
